# Объектно-ориентированное программирование
# Игра крестики-нолики человек-компьютер

Описание реализованных классов

-init(self) - инициализация игры (очистка игрового поля);  
-show(self) - отображение текущего состояния игрового поля;  
-human_go(self) - реализация хода игрока (запрашивает координаты свободной клетки и ставит туда крестик);  
-computer_go(self) - реализация хода компьютера (ставит случайным образом нолик в свободную клетку).  

-is_human_win - возвращает True, если победил человек, иначе - False;  
-is_computer_win - возвращает True, если победил компьютер, иначе - False;  
-is_draw - возвращает True, если ничья, иначе - False.  

-bool(game) - возвращает True, если игра не окончена (никто не победил и есть свободные клетки) и False - в противном случае.
